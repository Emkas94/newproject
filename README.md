# Modern Chat

Автономное чат-приложение с современным SPA-интерфейсом и полнотой функций мессенджера. Работает целиком на локальном SQLite и лёгком HTTP-слое без внешних зависимостей, поэтому поднимается в офлайн-среде одной командой.

## Ключевые возможности
- **Личные и групповые переписки**: создание чатов с набором участников, отображение участников в карточках.
- **Сообщения с файлами и эмодзи**: текстовые сообщения, загрузка вложений с сохранением оригинального имени и безопасным префиксом, смайлики через встроенный бар.
- **Боты с токен-авторизацией**: регистрация с уникальным токеном, добавление ботом владельца в чат, отправка и получение сообщений по API.
- **Администрирование**: флаг администратора у пользователя, просмотр логов любого чата и удаление сообщений (с зачисткой файлов) из админ-панели или через API.
- **Избранное**: закрепление чатов и сообщений, отдельная панель избранного и звёздочки в списке чатов и ленте сообщений.
- **Адаптивный интерфейс**: тёмная SPA, которая раскрывает сайдбар на десктопе и превращает его в выезжающее меню на мобильных, а также перестраивает компоновку редактора сообщений.
- **Полный офлайн-стек**: встроенные заглушки FastAPI/TestClient и простой HTTPServer без сторонних пакетов; при необходимости можно установить зависимости из `requirements.txt` и работать с реальным FastAPI/uvicorn.

## Запуск

```bash
python serve.py
```

Откройте `http://localhost:8000/`, создайте пользователей, затем добавьте их в чаты и отправляйте сообщения или файлы. Если нужно использовать uvicorn/fastapi, добавьте зависимости из `requirements.txt`, но для локальной проверки это не требуется. При загрузке вложений сервер сохраняет оригинальное имя, но кладёт файл на диск с уникальным префиксом, чтобы одинаковые имена не перезаписывали друг друга.

## Тестирование

Подробный сценарий запуска и проверки описан в [TESTING_INSTRUCTIONS.md](./TESTING_INSTRUCTIONS.md).

### Автоматические тесты API

Запустить проверки можно без установки внешних пакетов:

```bash
pytest
```

### Ручная проверка

1. Запустите сервер `python serve.py`.

2. В браузере откройте `http://localhost:8000/` — доступен одностраничный интерфейс. В левом сайдбаре создайте пользователей, откройте/создайте чат и отправьте текст/файл.

3. Для проверки API можно воспользоваться curl:

   ```bash
   # создание пользователя
   curl -X POST http://localhost:8000/users -H "Content-Type: application/json" -d '{"username":"alice"}'

   # создание приватного чата
   curl -X POST http://localhost:8000/chats -H "Content-Type: application/json" -d '{"participant_ids":[1,2],"is_group":false}'

   # отправка текстового сообщения
   curl -X POST http://localhost:8000/chats/1/messages -F "sender_id=1" -F "content=Привет!"

   # отправка файла
   curl -X POST http://localhost:8000/chats/1/messages -F "sender_id=1" -F "content=файл" -F "file=@README.md"
   ```

### Администрирование

- Чтобы создать администратора, при создании пользователя передайте `is_admin=true` (через UI это делается чекбоксом «Админ»).
- Просмотр логов чата: `GET /admin/chats/{chat_id}/logs?admin_id=<ID>` — возвращает историю чата даже если админ не участник.
- Удаление сообщений: `DELETE /admin/messages/{message_id}?admin_id=<ID>` — очищает запись и физически удаляет вложение, если оно было.
- В интерфейсе в левом сайдбаре есть блок «Админ-панель»: укажите ID администратора и чата, чтобы поднять логи и удалять сообщения кнопками.

### Избранное

- Добавить чат в избранное: `POST /favorites/chats` с телом `{ "user_id": 1, "chat_id": 2 }`. Удалить — `DELETE /favorites/chats?user_id=1&chat_id=2`.
- Добавить сообщение: `POST /favorites/messages` с телом `{ "user_id": 1, "message_id": 5 }`. Удалить — `DELETE /favorites/messages?user_id=1&message_id=5`.
- Получить весь список: `GET /users/{user_id}/favorites` — вернёт избранные чаты и сообщения пользователя.
- В UI есть карточки с ⭐: в списке чатов можно закрепить диалоги, а в ленте сообщений — конкретные сообщения. Панель «Избранное» в сайдбаре показывает актуальный список.

## API для ботов

Боты создаются владельцем и аутентифицируются токеном, который возвращает сервер. Пример потока:

```bash
# создать владельца и чат
curl -X POST http://localhost:8000/users -H "Content-Type: application/json" -d '{"username":"owner"}'
curl -X POST http://localhost:8000/users -H "Content-Type: application/json" -d '{"username":"guest"}'
curl -X POST http://localhost:8000/chats -H "Content-Type: application/json" -d '{"participant_ids":[1,2],"is_group":true,"name":"Squad"}'

# зарегистрировать бота и получить токен
BOT=$(curl -s -X POST http://localhost:8000/bots -H "Content-Type: application/json" -d '{"owner_id":1,"name":"Helper"}')
TOKEN=$(echo $BOT | python -c 'import json,sys;print(json.load(sys.stdin)["token"])')
BOT_ID=$(echo $BOT | python -c 'import json,sys;print(json.load(sys.stdin)["id"])')

# добавить бота в чат от имени владельца
curl -X POST http://localhost:8000/chats/1/bots/$BOT_ID -H "Content-Type: application/json" -d '{"owner_id":1}'

# отправить сообщение ботом в чат
curl -X POST http://localhost:8000/bots/$BOT_ID/messages -H "Content-Type: application/json" -d '{"token":"'$TOKEN'","chat_id":1,"content":"pong"}'

# получить обновления для бота (long-poll можно строить на этом запросе)
curl -X POST http://localhost:8000/bots/$BOT_ID/updates -H "Content-Type: application/json" -d '{"token":"'$TOKEN'","since_id":0}'
```

Правила безопасности: токен знает только владелец. Бот можно добавить лишь в те чаты, где состоит владелец.
